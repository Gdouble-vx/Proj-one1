📝 สรุปการตัดสินใจของ AI:

1. GNN อ่านโครงสร้างกราฟ — แต่ละ switch เป็น node, แต่ละ link เป็น edge
→ GATConv คำนวณว่า link ไหนเชื่อมกับ switch ที่มี loadสูง

2. Policy Head ออกน้ำหนัก — 50 ค่า (1.0–100.0) สำหรับแต่ละ link
→ ค่าต่ำ = ให้ traffic ผ่าน, ค่าสูง = หลีกเลี่ยง

3. ONOS ใช้น้ำหนักคำนวณ path — ส่ง link weights ไป ONOS REST API
→ ONOS path computation ใช้ weights เหล่านี้ในการหา shortest path

4. วัดผลจริง — ใช้ iperf3 วัด throughput, ping วัด latency
→ reward = throughput^1.2 / latency (Network Power metric)
