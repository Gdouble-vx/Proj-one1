🎯 สรุปผลสำหรับนำเสนอ

  • PPO+GNN ลด Latency 39% (0.06 vs 0.099 ms) — ดีกว่า IET paper (−9.16%) มาก
  • Reward +15.6% เทียบกับ Dijkstra baseline
  • Asymmetric: PPO+GNN เร็วกว่า OSPF 4.5 เท่า (+350.9%)
  • Transfer Learning ลดเวลา 7 เท่า (29.2h → 4.34h)
  • Reward Shaping v2 แก้ safe-action ได้จริง (0 → 5–10 links/step)
  • วัดผลบน ONOS 2.7.0 จริง — มีเพียงไม่กี่งานวิจัยที่ทำแบบนี้

💡 ข้อจำกัดที่ควรนำเสนอ

• Throughput +0.46% ใน ONOS eval ปกติ เพราะ topology มี bandwidth มากเกินไป — ต้องใช้ Asymmetric test
• ONOS fwd app ใช้ hop count — ต้อง install OpenFlow rules ตรงเพื่อควบคุม routing
