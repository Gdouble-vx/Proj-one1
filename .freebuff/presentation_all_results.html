SDN AI Agent Project — 2026

Problem Statement

OSPF Limitations

1. Hop-count metric ignores link bandwidth — sends traffic through narrow 15 Mbps links

2. No congestion awareness — doesn't adapt to traffic load

3. Suboptimal routing — 18.5% packet loss on asymmetric topology

Proposed Solution

✅ PPO + GNN (GAT) — learns optimal link weights from experience

✅ Reward Shaping — penalizes narrow link congestion

✅ Transfer Learning — pretrain → fine-tune approach

Goal: Build an AI agent that outperforms traditional routing (OSPF/ECMP) and other DRL methods on standard benchmark topologies.

Conclusions & Contributions

Key Results

1. PPO+GNN beats all 10 methods in throughput (+6.66%) and loss (-28.8%)

2. Training converges in 50k steps (~2 hours on CPU) with monotonic improvement

3. AI learns inverse-BW weighting — narrow links get high weight (80.5), wide links get low weight (1.1)

4. Zero-shot fails — GNN doesn't transfer across topologies (need fine-tune)

5. Fine-tune matches from-scratch on new topology — converges in 5k steps

Contributions

✅ Novel Reward Shaping — 4-component reward (metric + exploration + diversity + novelty)

✅ Transfer Learning Pipeline — pretrain → freeze GNN → fine-tune policy head

✅ Cross-Topology Test — NSFNET → Abilene zero-shot + fine-tune evaluation

✅ 11-Method Benchmark — fair comparison on same simulator/seeds/traffic

✅ Real ONOS Evaluation — 100k model tested on Mininet+ONOS 2.7.0
